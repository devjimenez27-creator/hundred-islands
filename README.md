# Hundred Islands Tourism Website

**Student Name:** Cecilio Jr. Q. Jimenez
**Selected Framework:** Next.js

## Project Description

The Hundred Islands Tourism Website is a tourism web application designed to showcase the natural beauty, attractions, and travel information of Hundred Islands in Pangasinan, Philippines.

The website provides information about the destination through a responsive and mobile-friendly interface.

## Technologies Used

- Next.js
- React
- HTML
- CSS
- JavaScript

## Main Sections

- Home
- About
- Attractions
- Gallery
- Location
